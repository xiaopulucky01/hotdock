# Hotdock Server

NestJS **platform core** for hot-pluggable business modules.

See [CORE.md](./CORE.md) for the full capability map, env vars, plugin SDK, and production notes.

```bash
npm install
npm run start:dev
# Health: http://localhost:3000/api/platform/health
# CLI:   npm run hotdock -- doctor
```

Default admin: `admin` / `admin123` (change in production).
